# Omnivara Desktop

Tauri-based desktop application for Omnivara One.

Reuses the `apps/web` Next.js frontend as the webview content.
Ideal for finance and ops teams needing a stable native desktop experience.

## Setup

1. Install Rust: https://rustup.rs
2. Install Tauri prerequisites: https://tauri.app/v2/start/prerequisites
3. Run `pnpm dev` from this directory
